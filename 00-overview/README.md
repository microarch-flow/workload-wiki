# Overview

本章正文以中文为主，目录和文件名使用英文。专有名词按需要保留英文。

## 本章定位

本章是整份 wiki 的导航层。它说明算法专题的范围、关键问题、相互关系和阅读路径。读者可以按目标选择页面，也可以用术语表和代表工作索引查阅相关内容。

芯片工作负载是可选的延伸方向。[Workload Lens](workload-lens.md) 介绍从算法到硬件分析的思路；具体刻画维度见 [Workload Characterization Axes](../06-chip-workload-analysis/workload-characterization-axes.md)。

## 页面列表

本页是 [Overview](README.md) 入口。下面的列表也是建议阅读顺序；已有基础的读者可以直接选择所需页面。

## 阅读顺序

1. [Wiki Roadmap](wiki-roadmap.md)：按目标选择算法或芯片工作负载阅读路径。
2. [Research Questions](research-questions.md)：了解 wiki 希望回答的问题和阅读目标。
3. [Unified Relationship Map](unified-relationship-map.md)：了解基础组件、任务、应用与工作负载之间的关系。
4. [Representative Works Index](representative-works-index.md)：从代表工作进入对应算法专题。
5. [Glossary](glossary.md)：按需查阅算法和硬件术语。
6. [Workload Lens](workload-lens.md)：按需延伸到算法工作负载和硬件分析。
